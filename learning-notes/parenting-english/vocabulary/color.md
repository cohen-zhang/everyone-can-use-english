## 本页怎么用

| 场景 | 怎么练 |
| --- | --- |
| **指物认色** | 指积木／衣服问 *What color is it?*，孩子答 *It's red.* |
| **分类收拾** | *Sort the red blocks and the blue blocks.* |
| **深浅** | 同一色加 *light* / *dark*：*light blue* · *dark green* |
| **成人拓展** | 基础色下的「引申／习语」给阿泽扫一眼；跟孩子练时先跳过习语 |

**音标：** 表内为 **IPA（美）**。英式拼写 **grey** 与美式 **gray** 并存，口语都认。

## 核心句型 · Core patterns

| English | 简中 |
| --- | --- |
| **What color is it?** | 它是什么颜色？ |
| **It's red. / It's a red apple.** | 它是红色的。／它是一个红苹果。 |
| **Is it blue or green?** | 它是蓝的还是绿的？ |
| **I like the pink one.** | 我喜欢粉色那个。 |
| **Sort them by color.** | 按颜色分类。 |
| **Pick a light / dark color.** | 选一个浅色／深色。 |

## 1. 基础八色 · Core colors

每色：**词 + 音标 + 亲子例句**；下方「引申」给家长／阿泽，跟唱认色时不必一次讲完。

### red — 红 `/red/`

**例句：** She wore a bright **red** dress to the party. — 她穿鲜红连衣裙去派对。  
**亲子：** *What color is the apple? — **Red**!*

| 向 | 含义 |
| --- | --- |
| 正面 | 热情、勇气；中式喜庆、好运 |
| 负面 | 愤怒、危险、赤字、血腥 |

| 短语 | 简中 |
| --- | --- |
| **red-letter day** | 大喜之日、值得纪念的一天 |
| **in the red** | （账目）亏损 |
| **see red** | 勃然大怒 |

### blue — 蓝 `/bluː/`

**例句：** The sky turns deep **blue** at noon. — 正午天空变成深蓝。  
**亲子：** *Look at the sky. It's **blue**.*

| 向 | 含义 |
| --- | --- |
| 常见意象 | 宁静、权威；也常指忧郁（*feel blue*） |

| 短语 | 简中 |
| --- | --- |
| **feel blue** | 情绪低落 |
| **out of the blue** | 突如其来 |
| **blue blood** | 贵族血统 |
| **blue movie** | 色情片（成人词；勿跟孩子练） |

### yellow — 黄 `/ˈjeləʊ/`

**例句：** Daffodils are pale **yellow** flowers in spring. — 黄水仙是春日浅黄的花。  
**亲子：** *The banana is **yellow**.*

| 文化 | 说明 |
| --- | --- |
| ⚠️ 中西差异 | **西方**常联懦弱、胆怯；**中文语境**多联尊贵、黄金、吉祥 |

| 短语 | 简中 |
| --- | --- |
| **yellow streak** | 胆小、怯懦的一面 |
| **yellow journalism** | 耸人听闻的小报式新闻 |

### green — 绿 `/ɡriːn/`

**例句：** Young leaves are light **green** in early spring. — 初春嫩叶是浅绿。  
**亲子：** *The grass is **green**. Go!*（绿灯／通行可顺带说 *green light*）

| 向 | 含义 |
| --- | --- |
| 正面 | 生机、环保、健康、通行 |
| 负面 | 青涩、不成熟；嫉妒 |

| 短语 | 简中 |
| --- | --- |
| **green with envy** | 十分嫉妒 |
| **green hand** / **greenhorn** | 新手（勿直译「绿色的手」） |
| **green light** | 批准、放行 |

### black — 黑 `/blæk/`

**例句：** He bought a sleek **black** leather briefcase. — 他买了精致的黑色公文包。  
**亲子：** *Night is **black**. The cat is **black**.*

| 向 | 含义 |
| --- | --- |
| 负面 | 死亡、邪恶、悲伤、非法、黑名单 |
| 正面 | 庄重、正式、高级（礼服、西装） |

| 短语 | 简中 |
| --- | --- |
| **black sheep** | 家族里「不合群／让人头疼」的那个 |
| **black market** | 黑市 |
| **in black and white** | 白纸黑字；非黑即白 |

### white — 白 `/waɪt/`

**例句：** The bride was dressed in pure **white**. — 新娘身着纯白婚纱。  
**亲子：** *Snow is **white**. Clouds can be **white**.*

| 文化 | 说明 |
| --- | --- |
| 西方 | 纯洁、和平（婚纱、白鸽） |
| ⚠️ 反差 | 中国传统里白色也曾表丧葬、哀悼 |

| 短语 | 简中 |
| --- | --- |
| **white lie** | 善意的谎言（不是「白色谎话」） |
| **white-collar** | 白领 |

### purple — 紫 `/ˈpɜːrpl/`

**例句：** Lavender has soft **purple** blossoms. — 薰衣草有柔和的紫色小花。  
**亲子：** *Grapes can be **purple**. Can you find something **purple**?*

| 向 | 含义 |
| --- | --- |
| 意象 | 皇权、尊贵、奢华、神秘（古罗马紫衣多属贵族） |

| 短语 | 简中 |
| --- | --- |
| **born in / to the purple** | 生于显贵世家 |

### orange — 橙 `/ˈɔːrɪndʒ/`

**例句：** The sunset painted the sky fiery **orange**. — 落日把天空染成炽热的橙红。  
**亲子：** *An **orange** is **orange**!*（水果名与颜色同形，可玩一句）

| 向 | 含义 |
| --- | --- |
| 意象 | 活力、温暖、丰收；也作警示色（路障、救生衣） |

## 2. 进阶常用色 · More colors

| English | IPA（美） | 简中 | 例句（English — 简中） | 引申／短语 |
| --- | --- | --- | --- | --- |
| **pink** | /pɪŋk/ | 粉 | Her room is soft **pink**. — 她房间是柔和粉色。 | 温柔、少女感；**pink slip** 解雇通知 |
| **brown** | /braʊn/ | 棕／褐 | This coffee is dark **brown**. — 这咖啡是深褐。 | 质朴、土地、复古；**brown goods** 家电（行业词） |
| **grey** / **gray** | /ɡreɪ/ | 灰 | The old wall is **grey**. — 旧墙是灰色的。 | 沉闷、中立；**grey area** 灰色地带 |
| **gold** | /ɡoʊld/ | 金 | She won a **gold** medal. — 她拿了金牌。 | 财富、荣耀、顶级 |
| **silver** | /ˈsɪlvər/ | 银 | **Silver** hair suited him. — 银发很衬他。 | 典雅、银牌、岁月感 |

## 3. 深浅与细分 · Shades（认色进阶）

适合和 Celine 指蜡笔、衣服时练「更具体一点」的说法。

| English | 简中 | 简易例句 |
| --- | --- | --- |
| **navy blue** | 藏青／深蓝 | **Navy blue** suits are common in offices. — 藏青西装在办公室很常见。 |
| **sky blue** | 天蓝 | Her schoolbag is **sky blue**. — 她的书包是天蓝色。 |
| **mint green** | 薄荷绿 | The cup is fresh **mint green**. — 杯子是清新薄荷绿。 |
| **cream** | 米白／奶油色 | The curtains are warm **cream**. — 窗帘是暖米白。 |
| **scarlet** | 猩红 | **Scarlet** is the color of many fire engines. — 很多消防车是猩红色。 |

### 构词小规律 · light / dark

| 结构 | 意思 | 例子 |
| --- | --- | --- |
| **light** + 颜色 | 浅…… | *light yellow* 浅黄 · *light blue* 浅蓝 |
| **dark** + 颜色 | 深…… | *dark green* 深绿 · *dark brown* 深褐 |
| **bright** + 颜色 | 鲜亮的…… | *bright red* 鲜红 |
| **pale** + 颜色 | 淡…… | *pale pink* 淡粉 |

## 4. 高频习语速查 · Idioms（家长向）

跟孩子认色时可不讲；考试／阅读里常考「别直译」。

| English | 简中 | 提醒 |
| --- | --- | --- |
| **green hand** / **greenhorn** | 新手 | 不是「绿色的手」 |
| **white lie** | 善意谎言 | 不是「白色谎话」 |
| **see red** | 发怒 | 和「看见红色」无关 |
| **feel blue** | 难过、郁闷 | 情绪，不是「感到蓝色」 |
| **out of the blue** | 突然 | 无预兆 |
| **grey area** | 灰色地带 | 规则／对错不清 |
| **in the red** | 亏损 | 账目用语 |
| **green light** | 放行、批准 | 可和交通灯实物对照教孩子 |

## 5. 亲子小练习 · Quick drill

| 家长问 | 孩子可答 |
| --- | --- |
| What color is the banana? | **Yellow!** |
| Is the grass light green or dark green? | **Light green** / **Dark green.** |
| Find something **purple**. | （指物）**This!** / **Grapes.** |
| Sort by color: red and blue. | （分两堆）**Done!** |
| What color do you like? | **I like pink.** / **Blue.** |

**进阶一句：** *It's a **light blue** cup, not navy.* — 这是浅蓝杯子，不是藏青。
