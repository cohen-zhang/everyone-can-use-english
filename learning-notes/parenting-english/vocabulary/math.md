## 本页怎么用

| 场景 | 怎么练 |
| --- | --- |
| **口算** | 家长念 *What is three plus five?*，孩子答 *Eight.* |
| **写竖式** | 指着式子说 *add / subtract / multiply / divide* |
| **按计算器** | 先分清 **CE** 和 **AC**（见下节） |

## 6. 计算器按键 · Calculator keys

家用四则计算器上，**CE** 和 **AC** 最容易混。记住：

| 按键 | 全称 | 简中 | 什么时候按 |
| --- | --- | --- | --- |
| **CE** | **Clear Entry** | 清除当前输入 | 刚按错一个数，只清掉这个数，前面的式子还在 |
| **AC** | **All Clear** | 全部清除 / 清零 | 整道题重算，清空显示和记忆中的运算 |

亲子口令：

- **Press CE.** — 按 CE。  
  *You typed 8 by mistake. Press **CE**, then type 9.* — 你误按了 8。按 **CE**，再输入 9。
- **Press AC.** — 按 AC。  
  *Start over. Press **AC**.* — 重来。按 **AC**。

### 其他常见键

| 按键 / 词 | 英文说法 | 简中 | 亲子例句 |
| --- | --- | --- | --- |
| **ON / OFF** | on / off | 开关 | **Turn the calculator on.** — 打开计算器。 |
| **+ − × ÷** | plus / minus / times / divided by | 加减乘除 | **Press times, then five.** — 按乘号，再按五。 |
| **=** | equals | 等于；得出结果 | **Press equals.** — 按等号。 |
| **.** | decimal point | 小数点 | **Press the decimal point.** — 按小数点。 |
| **%** | percent | 百分号 | **Press percent.** — 按百分号。 |
| **C** | clear | 清除（有的机型只有 C，作用接近 AC） | **Press C to clear.** — 按 C 清零。 |
| **√** | square root | 平方根（部分机型） | **Press square root.** — 按平方根。 |
| **M+ / M− / MR / MC** | memory plus / minus / recall / clear | 记忆加 / 减 / 调出 / 清除记忆 | **Press MR to recall the memory.** — 按 MR 调出记忆值。 |

**诚实标注：** 不同牌子的键名不完全一样。有的只印 **C**，有的印 **CE/C** 或 **DEL**。家里以机身印刷为准；跟孩子说时，**CE = 清刚才这个数，AC = 全部清光** 就够用。

## 7. 跟读小对话 · Mini dialogue

**场景：** 不多做口算，阿泽在旁边看她用计算器。

**阿泽：** What is twelve divided by three?  
**不多：** Four.  
**阿泽：** Good. Now check it on the calculator.  
**不多：** I pressed eight by mistake.  
**阿泽：** Press **CE**, then press three and equals.  
**不多：** It says four.  
**阿泽：** Nice. If you want a new problem, press **AC** first.

简中：

- 阿泽：十二除以三等于几？  
- 不多：四。  
- 阿泽：好。用计算器验算一下。  
- 不多：我不小心按了八。  
- 阿泽：按 **CE**，再按三和等号。  
- 不多：显示四。  
- 阿泽：很好。要算新题的话，先按 **AC**。
