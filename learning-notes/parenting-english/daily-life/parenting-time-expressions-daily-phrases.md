## 1. 问几点／读钟 — Telling the time

仓库里钟点句多散落在 Peppa、Jeff、家庭作息；本节把**读法**收齐。`亲子`

### 核心问句

| English | 简中 |
| --- | --- |
| **What time is it?** | 现在几点了？ |
| **What's the time?** | 几点了？（同义，略口语） |
| **What time is it on the clock?** | 钟上几点了？ |
| **What time do we …?** | 我们几点……？ |
| **What time is dinner / bath / bedtime?** | 晚饭／洗澡／睡觉几点？ |
| **Is it time for …?** | 到……的时间了吗？ |
| **It's time for … / It's time to …** | 该……了 |

**动画例：** *What time is it? — It's five o'clock in the morning.*（见 [[learning-notes/tv-series/peppa-pig/s01/scripts/Peppa.Pig.S01E43.My.Birthday.Party|Peppa S01E43]]）

### 整点与半点（先练）

| 说法 | 例子 | 简中 |
| --- | --- | --- |
| **… o'clock** | It's **seven o'clock**. | 七点整 |
| **half past …** | It's **half past six**. | 六点半（= 6:30） |
| **数字读法** | It's **six thirty**. | 六点三十（美式日常很常见） |

家庭作息里已有：*Dinner is at **six thirty**.* · *We wake up at **seven**.*（见 [[learning-notes/parenting-english/daily-life/parenting-family-rules-routine-daily-phrases|家庭守则与作息]]）

### 一刻钟（进阶）

| 说法 | 例子 | 简中 |
| --- | --- | --- |
| **quarter past …** | **quarter past seven** | 七点一刻（7:15） |
| **quarter to …** | **quarter to seven** | 差一刻七点（6:45） |
| **数字读法** | **six forty-five** / **seven fifteen** | 六点四十五／七点十五 |

Jeff 笔记里有 *6:45 a.m. = quarter to seven* 一类对照（见 [[learning-notes/tv-series/a-day-in-the-life-of-jeff/episode-notes/jeff-e02-cleaning-up-notes|Jeff E02]]）。

### a.m. / p.m. 与「早上／晚上」

缩写来自拉丁文（不必跟孩子背全称，家长知道来源即可）：

| 缩写 | 拉丁全称 | 字面 | 时段 |
| --- | --- | --- | --- |
| **a.m.** | **a**nte **m**eridiem | 正午**之前** | 午夜 → 正午 |
| **p.m.** | **p**ost **m**eridiem | 正午**之后** | 正午 → 午夜 |

- *meridiem* ≈ midday / **noon**（正午）  
- *ante* = before；*post* = after  

| English | 简中 | 备注 |
| --- | --- | --- |
| **a.m.** | 午夜—正午 | *seven a.m.* 早上七点（= ante meridiem） |
| **p.m.** | 正午—午夜 | *nine p.m.* 晚上九点（= post meridiem） |
| **in the morning / afternoon / evening** | 在早上／下午／傍晚 | 泛指时段用 **in** |
| **at night** | 在夜里 | 固定搭配；少说 *in the night*（叙事「夜里某时」才用） |
| **noon** / **midnight** | 正午／午夜 | *at noon* · *at midnight*；*noon* 即 a.m./p.m. 分界 |

作业场景：*Submit … before **nine p.m**.*（见 [[learning-notes/parenting-english/daily-life/parenting-homework-check-in-daily-phrases|作业打卡]]）

### 亲子跟读短句

| English | 简中 |
| --- | --- |
| **It's seven o'clock. Time to wake up!** | 七点了，该起床啦！ |
| **Dinner is at six thirty.** | 晚饭六点半。 |
| **Bath time is at eight.** | 八点洗澡。 |
| **Lights out at nine.** | 九点关灯。 |
| **What time do we leave for school?** | 我们几点出门上学？ |

## 2. 一天里的时段 — Parts of the day

| English | 简中 | 亲子例句 |
| --- | --- | --- |
| **morning** | 早上／上午 | *In the morning we brush our teeth.* — 早上我们刷牙。 |
| **noon** / **midday** | 中午 | *Lunch is around noon.* — 午饭大概中午。 |
| **afternoon** | 下午 | *After school in the afternoon…* — 下午放学后…… |
| **evening** | 傍晚／晚上（晚饭前后） | *In the evening we do homework.* — 晚上我们写作业。 |
| **night** | 夜里／夜晚 | *At night we sleep.* — 夜里我们睡觉。 |
| **midnight** | 午夜 | 成人向；孩子少用 |
| **weekend** | 周末 | *On the weekend we go to the park.* — 周末我们去公园。（美式常 *on the weekend*；英式常 *at the weekend*） |
| **weekday** / **school day** | 平日／上学日 | *On school days we wake up early.* — 上学日起得早。 |
| **peak hours** / **off-peak** | 高峰／非高峰 | 地铁场景 → [[learning-notes/parenting-english/daily-life/parenting-metro-scenario-phrases|地铁场景]] |

## 4. 多久 · 再几分钟 — Duration & countdowns

亲子冲突高频区：「再玩五分钟」「还要多久」。

| English | 简中 | 出处／场景 |
| --- | --- | --- |
| **How long …?** | 多久？ | *How long did that take?* — 花了多久？（秒表） |
| **How long until …?** | 还要多久才……？ | *How long until bedtime?* — 离睡觉还有多久？ |
| **five more minutes** | 再五分钟 | 洗澡／屏幕／出门前常见 |
| **You can have five more minutes, then…** | 再五分钟，然后…… | [[learning-notes/parenting-english/daily-life/parenting-bathing-daily-phrases|洗澡日常]] |
| **Almost bedtime** | 快到睡觉时间了 | 同上 |
| **Set a timer for two / ten / twenty minutes.** | 设两／十／二十分钟计时 | 作业、刷牙、兴趣 |
| **Take a ten-minute break.** | 休息十分钟 | [[learning-notes/parenting-english/daily-life/parenting-homework-check-in-daily-phrases|作业打卡]] |
| **Focus for twenty minutes, then break.** | 专心二十分钟再休息 | 同上 |
| **thirty minutes for math, twenty for Chinese** | 数学三十分钟、语文二十 | 估时 |
| **Time's up!** | 时间到！ | 游戏／计时结束 → [[learning-notes/parenting-english/games-and-activities/parenting-opposites-antonyms-game|正反义词 · 开始／结束]] |
| **It's been a long day.** | 今天好漫长 | 成人／情绪向；歌曲里也常见 |

**设备分工：** timer = 倒数还剩多久；stopwatch = 正数已经多久 → [§8](#8-设备钟闹钟计时器--clock-alarm-timer)。

### 一会儿 — a little while / for a bit

中文「一会儿」常指**短而不精确**的一段时间；英文里最贴的是 ***a little while*** / ***for a bit***，比 *five minutes* 更软、更好商量。`亲子`

| English | 简中 | 用法提示 |
| --- | --- | --- |
| **(just) for a little while** | （就）一会儿 | 允许短时停留／玩耍；*just* 强调「就一下」 |
| **for a while** | 一会儿／一阵子 | 比 *a little while* 略长一点，仍不精确 |
| **for a bit** / **for a little bit** | 一会儿 | 口语很常见；美式尤多 |
| **in a little while** | 过一会儿（之后） | **将来**：等一下再……（≠ *for a little while*） |
| **in a minute** / **in a sec** | 马上／一会儿就来 | 答应马上做；*sec* = second，很口语 |
| **after a while** | 过了一会儿 | **过去**：过了一阵之后 |
| **wait a while** / **wait a bit** | 等一会儿 | 让对方稍等 |
| **stay / play / visit for a little while** | 待／玩／看望一会儿 | 和动词搭配最自然 |

**和「再五分钟」怎么选：**

| 你想说 | 更自然的英文 |
| --- | --- |
| 就玩一会儿（不钉死几分钟） | *Just for a little while.* / *For a bit.* |
| 再五分钟就停 | *Five more minutes.*（可设 timer） |
| 我过一会儿再帮你 | *In a little while.* / *In a minute.* |

**Peppa 原句（过家家当医生）：** [[learning-notes/tv-series/peppa-pig/s01/scripts/Peppa.Pig.S01E04.Best.Friend|S01E04 Best Friend]]

> Can the patient have a visitor?  
> **Just for a little while.**  
> He might get tired.  
> — 病人可以有人来看望吗？／**就一会儿。**／他可能会累。

同集夸张时长对照（玩笑，不是真要躺三年）：

> I think you have to stay in bed **for three years**.  
> — 我觉得你得在床上躺**三年**。

**亲子跟读：**

| English | 简中 |
| --- | --- |
| **You can play for a little while, then we tidy up.** | 你可以玩一会儿，然后我们收拾。 |
| **Daddy can visit—just for a little while.** | 爸爸可以来看你——就一会儿。 |
| **Wait a bit. I'll be there in a minute.** | 等一会儿，我马上就来。 |
| **We'll leave in a little while.** | 我们过一会儿再走。 |

## 7. 介词速查 — at / on / in (time)

完整说明 → [[learning-notes/grammar-lab/介词#高频三角at--on--in|介词实验室 · 时间三角]]。

| 介词 | 用在 | 例子 |
| --- | --- | --- |
| **at** | 钟点、定点、*at night*、*at noon* | *at seven* · *at six thirty* · *at the weekend*（英） |
| **on** | 星期、日期、某个具体上午 | *on Monday* · *on July 4* · *on Monday morning* |
| **in** | 月、季、年、泛指 morning/afternoon/evening | *in July* · *in spring* · *in the morning* |

**不再加介词：** *this / next / last + Monday* → *See you next Monday.*（不说 *on next Monday*）

## 9. 亲子小练习 — Quick drill

| 家长 | 孩子可答 |
| --- | --- |
| What time is it? (指着 7:00) | **It's seven o'clock.** |
| What time is it? (指着 6:30) | **It's six thirty.** / **Half past six.** |
| What day is it today? | **It's ___day.** |
| Is it morning or night? | **Morning!** / **Night!** |
| How long until bedtime? | **Ten more minutes!** |
| Can we play a little longer? | **Just for a little while.** / **For a bit.** |
| How often do we go to the park? | **Every weekend.** / **Once a week.** |
| Set a timer for five minutes. | （操作）**OK!** · **Timer's on.** |
| What time is dinner? | **Six thirty.** |

**进阶：** 指表问 *Is it quarter past or quarter to?*；用 *before / after* 说 *before dinner / after school*。

## 10. 英文短文 · 阿泽自述（时间表达日常）

*约 1–2 分钟 · 描述训练 · 串联本页常用句*

**English**

Time expressions run through our whole day with Celine.  
In the morning, I start with clock time: "It's seven ten." "Breakfast in ten minutes."  
Then I use sequence words so she feels structure: first, next, then, finally.  

For school days, we practice day and date language.  
"Today is Thursday." "Tomorrow is Friday." "Your class starts at eight."  
I keep repeating **at**, **on**, and **in** naturally:  
at 8:00, on Monday, in summer.  

During homework and play, countdown language helps transitions.  
"Five more minutes." "Let's finish in ten." "Break starts in two minutes."  
This reduces arguing because expectations are clear.  

I also build frequency habits:  
"We read every day." "You have dance class twice a week."  
These patterns make planning easier for both of us.  

At night, I close with tomorrow talk:  
what time to wake up, what time to leave, and what to prepare before bed.  
For me, teaching time language is not grammar only.  
It is life management, emotional stability, and family rhythm.

**简中：**

在我们家，时间表达贯穿整天。  
早上先练钟点：现在七点十分、十分钟后吃早餐。  
再用顺序词让流程清楚：先、再、然后、最后。  

上学场景会反复练今天明天和星期：今天周四、明天周五、八点上课。  
介词也自然重复：at 8:00，on Monday，in summer。  

作业和玩耍切换时，用倒计时最有效：  
还有五分钟、十分钟内做完、两分钟后休息。  
边界清楚了，拉扯就少。  

我也会练频率表达：每天读书、每周两次舞蹈课。  
这种句型对家庭安排很实用。  

晚上再收束明天的时间点：几点起、几点出门、睡前要准备什么。  
对我来说，时间英语不只是语法，而是生活管理、情绪稳定和家庭节奏。
