# 电器使用日常 — Appliances & Home Electronics

**索引：** [[learning-notes/parenting-english/README|亲子英文材料索引]]


亲子在家使用各类电器时的高频英文表达，含安全提醒、简单指令与可复读句式。`亲子`

---

## 1. 安全总览 — Safety First

### 不碰、不关（危险区）

- **Don’t touch the socket / outlet.**  
不要碰插座。`亲子`
- **Electricity and water don’t mix.**  
电和水不能混在一起。（洗澡、手湿时不要碰电器）`亲子`
- **Unplug it first.** / **Make sure it’s unplugged.**  
先拔掉插头。/ 确认已经拔掉插头。
- **That’s not a toy. Hands off.**  
那不是玩具。别碰。`亲子`
- **Only grown-ups can plug this in. Ask me first.**  
只有大人能插这个。先问爸爸妈妈。`亲子`
- **The cord is for adults to handle, okay?**  
电线要大人来弄，好吗？

### 可以、一起做

- **I’ll help you turn it on safely.**  
我帮你安全地打开。
- **We use this together.**  
我们一起用。
- **You can press this button, but I’ll hold the device.**  
你可以按这个键，我拿着设备。

## 2. 灯与空调 — Lights & Climate

### 灯

- **Turn the light on / off.** / **Switch the light on / off.**  
开灯 / 关灯。
- **The switch is on the wall.**  
开关在墙上。
- **It’s too bright. Let’s use the desk lamp only.**  
太亮了。我们只用台灯吧。
- **It’s a bit dim. We need more light.**  
有点暗。我们需要多一点的灯。
- **The bulb burned out. We need a new one.** / **(UK) The bulb is broken.**  
灯泡烧坏了。要换个新的。/（英式也可说 The bulb is broken.）
- **The night light stays on. It helps you sleep.**  
小夜灯一直亮着。帮你睡觉用。`亲子`

### 空调

- **Turn the AC on. / Turn on the air conditioner.**  
打开空调。`亲子`
- **It’s so hot. Let’s set the temperature lower.** / **A bit cooler, please.**  
好热。我们把温度调低一点。/ 再凉一点。`亲子`
- **It’s too cold. Raise the temperature a little. / Make it warmer.**  
太冷了。把温度调高一点。/ 让屋里暖一点。
- **The AC is too strong. Turn it down a bit.** / **Use fan mode only.**  
空调开太大了。关小一点。/ 只开送风。  
*（turn down 在家用时多指关小、减弱。）*
- **Use the remote. / Pass me the remote.**  
用遥控器。/ 把遥控器递给我。
- **The fan is enough. We don’t need the AC today.**  
电风扇够了。今天不用空调。
- **The air filter needs cleaning. I’ll do it on the weekend.**  
滤网要洗了。我周末来弄。

## 3. 厨房电器 — Kitchen Appliances

### 冰箱、微波炉、烧水壶等

- **The fridge is too full. We need to finish these leftovers first.**  
冰箱太满了。我们要先把这些剩菜吃完。
- **Don’t play with the fridge door. It wastes electricity.**  
别玩冰箱门。浪费电。`亲子`
- **The microwave is hot inside. Don’t open it by yourself.**  
微波炉里面很烫。别自己开。`亲子`
- **The microwave beeped. It’s done. Don’t touch the bowl—it’s very hot. Use a mitt.**  
微波炉响了。好了。别碰碗——很烫。用隔热手套。`亲子`
- **I’ll reheat the milk for 30 seconds.** / **I’ll set it for 30 seconds.**  
我把牛奶再热 30 秒。/ 我设 30 秒。
- **The kettle is boiling. Stay back.** / **The kettle is on. Don’t touch.**  
水正在烧。站远一点。/ 水壶开着。别碰。`亲子`
- **I’m making rice in the rice cooker. Don’t open the lid.**  
用电饭煲煮饭。别揭盖。`亲子`
- **The blender is loud. Step back when it’s on.**  
搅拌机很响。开的时候站远一点。`亲子`
- **Dishwasher’s running. Don’t open the door or you’ll get wet.**  
洗碗机正在洗。别开门，会溅到水。`亲子`
- **The oven is preheating. Don’t go near the door.**  
烤箱在预热。别靠门站。`亲子`

## 4. 洗衣与清洁 — Laundry & Cleaning

- **I’m doing a load of laundry. Don’t add random stuff to the washer.**  
我在洗一批衣服。别往洗衣机里乱塞东西。`亲子`
- **The washing machine is running. The floor can get a little wet—watch your step.**  
洗衣机在转。地上可能有点水——注意脚下。`亲子`
- **I’m going to start the spin cycle. It might be noisy for a bit.**  
我要开脱水。可能会响一会儿。`亲子`
- **I’m going to run the robot vacuum. Pick up the small toys first.**  
我要开扫地机。先把小玩具收起来。`亲子`
- **The vacuum is loud, but it’s not scary. It sucks up dust.** / **(UK) The hoover is loud...**  
吸尘器很响，但不可怕。它把灰吸走。/（英：hoover 作名词也可指吸尘器品牌泛化。）

## 5. 电视、平板、音箱 — Screen & Audio

- **It’s not screen time right now. We’ll watch after dinner.**  
现在不是看屏幕时间。我们晚饭后再看。`亲子`
- **We’ve been watching for 20 minutes. That’s the rule.**  
已经看了 20 分钟。规矩就是这样。`亲子`
- **The volume is too high. I’m turning it down.**  
声音太大。我调小一点。`亲子`
- **Subtitles on or off?** / **Do you need subtitles?**  
字幕要开还是关？/ 你需要字幕吗？`技术`
- **The battery is low. It needs to charge. Hand me the cable.** / **(UK) The battery’s flat. We need to charge it.**  
电量低了。要充电。把线递给我。/（英：the battery’s flat.）
- **The router / Wi-Fi is slow today. The video might buffer.** / **(UK) The internet’s a bit slow...**  
路由器 / Wi-Fi 今天有点慢。视频可能会转圈。`技术`
- **Daddy’s on a work call. Please don’t use the speaker.**  
爸爸在开会。别用外放。`技术`
- **The Bluetooth speaker is connected. The sound comes from the box.** / **(UK) The Bluetooth speaker is paired.**  
蓝牙音箱连上了。声音从那个盒子里出来。/（英：已配对 paired。）`技术`

## 6. 电池与插线 — Power & Cords

- **The batteries are dead. We need new ones.** / **(UK) The batteries are flat.**  
电池没电了。要换新的。/（英：flat.）
- **This takes AA or AAA. Let me show you the difference once.**  
这要用五号或七号。我教你认一次。`技术`
- **The power strip is full. We can’t plug in another thing right here.**  
插线板满了。这里不能再插了。`技术`
- **Coil the cable so nobody trips. Don’t yank the cord when you unplug.**  
把线绕好，别绊到人。拔插头时别硬拽。`亲子`
- **A short-circuit is dangerous. We call an electrician for this.** / **(UK) A short is dangerous. We get an electrician in.**  
短路很危险。这个要请电工。`技术`

## 7. 短对话（阿泽、不多、Celine）

**场景 A：开客厅空调**

- **阿泽 (Dad)**: Celine, it’s stuffy. Do you want the AC?  
- **Celine (不多)**: Yes, please!  
- **Dad**: Okay. I’ll set it to 26. Don’t play with the remote. If you feel cold, tell me.  
- **Celine**: Okay. I’ll tell you.  
— 泽哥 / 阿泽和 Celine（不多）说客厅有点闷。爸爸问要不要开空调，说设 26 度，别玩遥控器，冷要说。

**场景 B：洗衣机在响**

- **Dad**: The washing machine is on. It might shake a little. It’s normal.  
- **Celine**: It’s loud!  
- **Dad**: It’s finishing the spin. Stay away from the machine until it beeps, okay?  
- **Celine**: Okay!  
— 告诉孩子洗衣机在转、会晃、有声音都正常，听到提示音前不要靠近。`亲子`

**场景 C：关电视去睡觉**

- **Dad**: Time to turn the TV off. It’s bedtime.  
- **Celine**: One more minute?  
- **Dad**: We already said two rounds of Peppa. Let’s do teeth and a story.  
- **Celine**: Okay…  
— 坚定执行约定，用「刷牙+故事」过渡。`亲子`

## 8. 小词表（亲子优先）


| English                                   | 简中              | 备注        |
| ----------------------------------------- | --------------- | --------- |
| **appliance**                             | 电器（多指大家电 / 小家电） | 日常家用      |
| **plug in / unplug**                      | 插电 / 拔插头        | 安全高频      |
| **outlet** / (UK) **socket**              | 墙插              | 地区用词      |
| **power strip** / (UK) **extension lead** | 插线板 / 延长线带多孔    | 看款式       |
| **remote (control)**                      | 遥控器             | TV、空调通用   |
| **AC / air conditioner**                  | 空调              | 口语 AC 很常用 |
| **reheat**                                | 用微波炉等再热         | 厨房        |
| **spin cycle**                            | （洗衣机）脱水         | 孩子可能好奇响动  |
| **buffer**                                | （视频）缓冲、转圈       | 屏类 `技术`   |
| **charge / charging cable**               | 充电 / 充电线        | 数码        |
