## 1. 核心句型 — Key patterns

| Pattern | 中文 | 例句（可跟读） |
| --- | --- | --- |
| How are the seasons different? | 四季有什么不同？ | Spring is warm. Winter is cold. |
| What's the weather like in …? | ……天气怎么样？ | What's the weather like in summer? — It's hot. |
| In spring / summer / autumn / winter, … | 在春／夏／秋／冬…… | In autumn, leaves fall. |
| I like … because … | 我喜欢……因为…… | I like spring because it's warm. |
