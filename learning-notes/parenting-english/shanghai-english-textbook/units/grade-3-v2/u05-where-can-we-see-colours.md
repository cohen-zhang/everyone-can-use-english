## 1. 核心句型 — Key patterns

| Pattern | 中文 | 例句（可跟读） |
| --- | --- | --- |
| Where can we see colours? | 哪里能看到颜色？ | We can see colours in the park / sky / rainbow. |
| What colour is it? | 它是什么颜色？ | What colour is it? — It's red. |
| What colour do you like? | 你喜欢什么颜色？ | I like blue. |
| It's … | 它是……色 | It's green. They're yellow. |
| I can see … | 我能看见…… | I can see a rainbow. |
