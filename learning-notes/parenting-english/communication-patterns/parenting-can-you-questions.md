# Why Chinese students can’t speak English properly

**索引：** [[learning-notes/parenting-english/README|亲子英文材料索引]]


学习笔记：口语里 **Can you** 的误用、问语言能力的说法，以及「翻译式英语」问题。

**相关：** [[learning-notes/parenting-english/communication-patterns/parenting-question-bank-by-category.md|亲子问句分类清单]]

---

## 1. 想确认对方是否听懂时，别乱用 *Can you…?* `术语`

当你想确认对方有没有听懂你在说什么时，一般**不说**：

- *Can you understand?* — 听起来像在**质疑对方有没有能力听懂**，容易显得不礼貌。

**可以改用：**


| English                                  | 中文           |
| ---------------------------------------- | ------------ |
| **You got it?**                          | 明白了吗？ / 懂了吗？ |
| **Did I make sense?**                    | 我讲清楚了吗？      |
| **Do you get what I’m saying?**          | 你懂我意思吗？      |
| **Do you get / see / know what I mean?** | 你明白我指的是什么吗？  |


---

## 2. 问「会不会某种语言」时同理

一般**不常问**：

- *Can you speak English?* — 同样像在质疑能力。

**更常见的说法：**


| English                   | 中文      |
| ------------------------- | ------- |
| **Do you speak English?** | 你会说英语吗？ |


---

## 3. 可以听不懂，但要会问

听不懂时可以说：


| English                         | 中文          |
| ------------------------------- | ----------- |
| **Excuse me?**                  | 嗯？ / 请再说一遍？ |
| **Pardon?**                     | 请重复一下？      |
| **Come again?**                 | 再说一遍？（口语）   |
| **Sorry, I didn’t catch that.** | 抱歉，我没听清。    |


---

## 4. 说不好英语，根子往往不在「环境 / 好老师」

原文观点：**真正的原因**往往很简单——你是在用 **translation（翻译）** 学英语，而不是用 **comprehension（理解）**。

- 有人问：*How do you say「卖萌」in English?* *How do you say「笑掉大牙」in English?* — 总在找**和某个中文一一对应的**那句英文。
- 但英语**不总是一对一换词**；就算告诉你一句 *Laugh my teeth off*，对外国人说也可能**完全不通**。

**类比（What is a CAR?）**

- 正确思路：*It’s that four-wheel vehicle you see on the streets.* — 用英语**描述概念**。
- 若心里先想「汽车」再套英文，就还是在用**英语发音说中文思维**。

Otherwise, you’re not really speaking English—you’re only using English words to speak Chinese.
