## 重点表达 · Key Phrases

先收能拿去说话的短语。备注里标 `技术` 的，是写代码时会碰的词；歌里把它们唱成了对手或装备。

| English | 简中 | 备注 |
| --- | --- | --- |
| **my jam** | 我的菜；最对味的那样 | *Java's my jam.* *jam* 原可指即兴合奏，口语里就是「我就爱这个」 |
| **casting a spell / under its spell** | 施咒 / 被迷住 | 先写敲键盘像施法，再写自己中了 Java 的咒 |
| **got stories to tell** | 有故事要讲 | *have got* 的口语。屏幕一闪，像有话要说 |
| **coffee in hand** | 咖啡在手 | 手里端着咖啡就开工 |
| **buddy** | 哥们儿；搭档 | 比 *friend* 更随便 |
| **geeky delight** | 极客才懂的那种开心 | *geeky* 带极客气；*delight* 让人高兴的事 |
| **crashing or running** | 崩了也好，跑着也好 | `技术`。程序两种状态。*or* 在这里是「无论哪一种」 |
| **coding all night** | 通宵写代码 | *all night* 一整夜 |
| **debugging** | 调试；捉虫 | `技术`。*bug* 是缺陷，*debug* 是把虫捉掉。*dragons* 是把 bug 唱成龙 |
| **ready to fight** | 准备迎战 | 接上一句：龙来了，我打 |
| **code-knight in light** | 光里的代码骑士 | 套 *a knight in shining armor*（救场的骑士）。*in light* 是屏幕的光 |
| **I laugh and I fix** | 我笑一声，然后修掉 | 两个 *I* 把「不当回事」和「动手修」连在一起 |
| **loops and conditions** | 循环和条件 | `技术`。*play all the tricks* 是把招数都使出来，*tricks* 这里是手法 |
| **stack overflow** | 栈溢出 | `技术`。调用栈叠满了。同词也是技术问答网站名 |
| **part of the mix** | 这摊事里本来就有的一件 | *mix* 是局面、混合。溢出也被算进日常 |
| **with a wink** | 眨一下眼；带着俏皮 | 不是 *in a blink*（一眨眼的工夫） |
| **real quick** | 很快 | 口语用 *real* 代替 *really*。书面仍写 *really quickly* |
| **line up in rows** | 排成一排排 | `技术`：*semicolon* 分号，像站队 |
| **syntax clean** | 语法干净 | `技术`。*syntax* 是写法规则 |
| **my mind just flows** | 思路一下子顺了 | *flow* 流淌；写的时候那种顺 |
| **nulls can't stop me** | null 挡不住我 | `技术`。*null* 是「没有这个对象」。复数把它们唱成一个个对手 |
| **refactor** | 重构 | `技术`。功能不变，把代码整理清楚。歌里连生活一起重构 |
| **no need to stress** | 不必紧张 | *stress* 这里是动词：加压、焦虑 |
| **make a mess** | 搞砸；弄乱 | 常和下一句一起记 |
| **Ctrl+Z** | 撤销 | 口语说 *control z*。搞砸了就撤销 |
| **feel the zest** | 来了兴致 | *zest* 热情、兴味。上一句 *IDE's glowing*：`技术`，IDE 屏幕亮着 |
| **Java's my suit** | Java 是我的战衣 | 接 *code-knight*。穿上的是战衣，不是商务西装 |
| **feeling blessed** | 觉得很幸运 | 口语感叹，常带一点夸张 |

## 听歌提示 · Listening Notes

- 副歌先唱稳四句。钩子是 *Java, my buddy* 和 *Crashing or running*。桥段再换词。
- *my jam* 重音在 **jam**。*real quick* 两个词都短，不要唱成 *really quickly*。
- *code-knight in light* 不要按字面理解成「光里的骑士代码」。它套的是 *knight in shining armor*。
- *Java's my suit* 的 *suit* 是战衣。*feeling blessed* 是「太幸运了」，不是宗教课文。
- *with a wink* 是表情；*in a blink* 才是「一眨眼」。
- `技术` 词先对上文的表，再回听：*debug*、*stack overflow*、*null*、*refactor*、*syntax*、*semicolon*。词义见 [[learning-notes/personal-english-book/study/computer-science-vocab-interesting|计算机词汇]] 和 [[learning-notes/personal-english-book/study/java-exception-handling|异常处理]]。
