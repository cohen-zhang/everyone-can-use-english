## 1. 一首歌怎么分段 — Song Structure

流行歌常见「积木」如下。听歌时可对照歌词标题里的 **Verse / Chorus**。

| English | IPA（美） | 简中 | 听感 / 作用 |
| --- | --- | --- | --- |
| **intro** | /ˈɪntroʊ/ | 前奏 | 乐器先入；常无主唱或只有哼唱 |
| **verse** | /vɜːrs/ | 主歌 | 讲故事、推进情节；每段歌词常不同 |
| **pre-chorus** | /ˌpriː ˈkɔːrəs/ | 预副歌 | 蓄力；把情绪推到副歌 |
| **chorus** / **hook** | /ˈkɔːrəs; hʊk/ | 副歌 / 钩子句 | 最易记、最常重复；**hook** 也可单指抓耳那一句 |
| **post-chorus** | /ˌpoʊst ˈkɔːrəs/ | 副歌后段 | 副歌后的短重复或舞蹈句 |
| **bridge** | /brɪdʒ/ | 桥段 | 中后段「换气」；旋律或歌词换新角度 |
| **solo** | /ˈsoʊloʊ/ | 独奏 | 吉他/人声等单独炫技一段 |
| **breakdown** | /ˈbreɪkdaʊn/ | 分解段 | 鼓点或配器变稀，常用于电子/舞曲 |
| **outro** | /ˈaʊtroʊ/ | 尾奏 | 收尾；渐弱或最后一句重复 |
| **interlude** | /ˈɪntərluːd/ | 间奏 | 两段之间的器乐过渡 |
| **refrain** | /rɪˈfreɪn/ | （广义）反复句 | 有时≈chorus；民谣里常指固定重复句 |

**典型流行结构（举例）：**

`Intro → Verse 1 → Pre-chorus → Chorus → Verse 2 → Pre-chorus → Chorus → Bridge → Chorus → Outro`

**说唱 / 对唱常多写：**

| English | 简中 | 说明 |
| --- | --- | --- |
| **verse 1 / verse 2** | 第一段 / 第二段主歌 | 说唱常一人一段 **verse** |
| **hook** | 钩子（副歌位） | 常由客串歌手唱，见 **feat.** |
| **duet** | 对唱 | 两人主唱分量接近（如 Lady Gaga & Bruno Mars） |
| **ad-lib** | 即兴衬词 | 「yeah / uh」等点缀，多在副歌尾 |

## 2. 歌名括号里常见字 — Credits & Editions

### 2.1 **feat.** = featured（客串）

| 写法 | 全称 | 简中 | 怎么理解 |
| --- | --- | --- | --- |
| **feat.** / **ft.** / **featuring** | featured | 客串 / 合作演唱 | 主艺人歌里请来另一位艺人唱一段（常是 hook / verse） |
| **with** | with | 与……合作 | 有时≈feat.；偏「并列合作」语气 |
| **&** / **x** / **vs.** | and / versus | 与 / 对战合作 | **&** 多为双主唱；**vs.** 多见于 remix 或 DJ 对打企划 |
| **prod.** | produced by | 制作人是…… | 电子舞曲常见，强调制作而非演唱 |

**读法：** *feat.* 口语常读作 **/fiːt/** 或直接说 **featuring**。

**本库例子：**

- *Love the Way You Lie **(feat. Rihanna)*** — Eminem 主唱说唱段，Rihanna 唱副歌  
- *See You Again **(feat. Charlie Puth)*** — Wiz Khalifa 说唱，Charlie Puth 唱 hook  
- *Somebody That I Used to Know **(feat. Kimbra)*** — Gotye 主唱，Kimbra 客串女声  

**不等于：**

| 写法 | 含义 |
| --- | --- |
| **cover** | 翻唱别人的歌 |
| **remix** | 在原曲上重混编曲/节奏 |
| **remaster** | 母带重新母带处理（音色更清晰），一般不改曲式 |
| **acoustic** | 原声版（吉他/钢琴为主） |
| **live** | 现场版 |
| **demo** | 小样 / 试听版 |
| **radio edit** | 电台剪辑版（常更短、少粗口） |
| **explicit** / **clean** | 含脏词版 / 净版 |
| **Taylor’s Version** 等 | 艺人重录/再授权版本（非 feat.） |

**一句话：** 歌名里的 **feat. X** ≈「这首歌请来了 **X** 一起唱」；主艺人仍写在歌手栏。

## 3. 曲风 · Genre（本库标签对照）

本库总表「曲风」列与笔记 `genre/` 标签常用这些词：

| Genre | 简中 | 听感速记 |
| --- | --- | --- |
| **Pop** | 流行 | 旋律向、结构清晰、易跟唱 |
| **Ballad** | 抒情慢歌 | 慢板、情绪重，常钢琴/弦乐 |
| **Rock** | 摇滚 | 电吉他、鼓点更硬 |
| **Hip-hop** / **Rap** | 嘻哈 / 说唱 | 节奏口白、押韵为主 |
| **R&B** | 节奏布鲁斯 | 节奏与唱腔偏灵魂乐、滑音多 |
| **Country** | 乡村 | 叙事感、常有吉他与故事线 |
| **EDM** / **Dance** | 电子舞曲 | 强拍、适合派对 |
| **Jazz** | 爵士 | 即兴、摇摆节奏（如 *Fly Me to the Moon*） |
| **Soundtrack** / OST | 影视原声 | 为电影/剧集创作或选用 |

一首歌可多标签（如 **Hip-hop · Pop**）。

## 4. 主题分类 — Theme（本库文件夹）

按**歌词主题**归文件夹（一首歌只进一个主文件夹）：

| 文件夹 / 主题 | English hint | 典型情绪 |
| --- | --- | --- |
| `breakup-loss` 分手·思念 | breakup, missing someone | 分开、怀念、遗憾 |
| `love-romance` 恋爱 | love, romance | 心动、表白、甜蜜 |
| `emotions` 情绪 | mood, feelings | 愤怒、空虚、亢奋等 |
| `life-attitude` 生活态度 | mindset, attitude | 励志、自我、处世 |
| `relationships` 关系 | relationships | 人际拉扯、边界 |
| `Celine/` 儿歌 | children's songs | 亲子跟唱 |

总表另有场景列：**通勤 · 精研 · KTV · 发音**——选歌练法用，不是曲风。

## 5. 发行与形态 — Releases（够用即可）

| English | 简中 | 最小理解 |
| --- | --- | --- |
| **single** | 单曲 | 单独发行的一首（或两首） |
| **album** | 专辑 | 一组歌（常 8–15+ 首） |
| **EP** | 迷你专辑 | 比单曲多、比专辑短（约 4–7 首） |
| **track** | 曲目 | 专辑里的第几首 |
| **title track** | 同名主打 | 与专辑同名或主推曲 |
| **A-side / B-side** | A/B 面 | 黑胶时代说法；现多指主打 vs 附送曲 |
| **chart** / **No. 1** | 榜单 / 冠军 | Billboard 等销量/播放排行 |
| **BPM** | 每分钟拍数 | 节奏快慢（可选了解） |
| **key** | 调性 | 如 C major；学唱时可后补 |

## 6. 听歌学英语：最小工作流

1. **先听结构：** 找出哪段在重复 → 那多半是 **chorus / hook**。  
2. **再看歌名括号：** 有 **feat.** 就留意客串段落从哪里开始。  
3. **跟唱顺序：** Verse（故事）→ Chorus（核心句）→ Bridge（转折句）。  
4. **本库笔记：** 「英文歌词」跟唱 → 「中文翻译」核对 → 「重点表达」收短语。

## 7. 英文短文 · 阿泽自述（听歌术语）

*约 1 分钟 · 把上面术语串成口语*

**English**

When I study English songs, I don't start with every lyric.  
I first map the **structure**: **intro**, **verse**, **chorus**, **bridge**, then **outro**.  
The **chorus**—or **hook**—is the part I memorize first, because it repeats.  
If the title says **feat.** someone, I know a guest singer joins, often on the hook.  
A **remix** changes the beat; a **cover** is someone else singing the song; a **remaster** mostly upgrades the sound.  
In this vault, songs are sorted by **theme**—breakup, love, emotions—and tagged by **genre** like pop, hip-hop, or ballad.  
That tiny toolkit is enough to read any song note without getting lost.

**简中：**

学英文歌我不会一上来抠每句歌词。  
先分清结构：前奏、主歌、副歌、桥段、尾奏。  
副歌（hook）最先背，因为会反复出现。  
歌名里写 **feat.**，就知道有客串，常在副歌位置。  
Remix 改编曲，Cover 是翻唱，Remaster 多半只是音质升级。  
本库按主题分夹，再标曲风。  
这套最小术语，够读任何一首歌的笔记而不迷路。

## 8. 一句话复习

**Verse tells the story; chorus sells the hook; feat. means a guest joins the ride.**  
主歌讲故事，副歌卖钩子；feat. 就是请来客串一起唱。
