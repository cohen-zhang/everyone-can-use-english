# 生活态度（`life-attitude`）

本主题下英文歌曲学习笔记。完整曲目表见 [[learning-notes/english-song/README|英文歌曲索引]]。

侧栏只显示本索引；单曲页可通过下方链接或站内搜索打开。

## 中年歌单

来自中年听歌路线。第 8–10 关连着听：**别提前写完故事 → 别急着赶完 → 按自己的方式走完。** 另外三首：**来不及说的话 → 先陪着，不急着修好 → 轻一点回到日常。**

- [[learning-notes/english-song/life-attitude/dont-stop-believin-journey|Don't Stop Believin' — Journey]]（希望）
- [[learning-notes/english-song/life-attitude/vienna-billy-joel|Vienna — Billy Joel]]（焦虑与自我和解）
- [[learning-notes/english-song/life-attitude/my-way-frank-sinatra|My Way — Frank Sinatra]]（人生总结）
- [[learning-notes/english-song/life-attitude/the-living-years-mike-and-the-mechanics|The Living Years — Mike + The Mechanics]]（代际沟通与遗憾；与《当你老了》同一主题）
- [[learning-notes/english-song/life-attitude/fix-you-coldplay|Fix You — Coldplay]]（低谷中的陪伴；放在《重头再来》之前）
- [[learning-notes/english-song/life-attitude/here-comes-the-sun-the-beatles|Here Comes the Sun — The Beatles]]（轻盈地重新开始）
