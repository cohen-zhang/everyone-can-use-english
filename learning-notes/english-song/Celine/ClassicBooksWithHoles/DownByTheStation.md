## 歌词 · Lyrics

> 依据 Child's Play / Jess Stockham 版与配套 CD 整理（廖彩杏书单常用本）。每节前两行固定；第三、四行随车辆变化。部分版本第一节用 **pufferbellies**、**station master**、*Puff, puff, toot, toot*，本绘本用 **puffer trains**、**engine driver**、*CHUFF!*

### 1 · Puffer trains 蒸汽小火车

Down by the station,  
Early in the morning,  
See the little **puffer trains**,  
All in a row.  
See the **engine driver**  
Pull the little handle;  
**CHUFF! CHUFF! CHUFF!**  
And off we go! — 大清早车站边，喷气小火车排成排；火车司机拉把手——嚓呋！出发啦！

### 2 · Busy buses 公交车

Down by the station,  
Early in the morning,  
See the **busy buses**,  
All in a row.  
See the **bus driver**  
Calling to the passengers;  
**BRRM! BRRM! BRRM!**  
And off we go! — Busy buses 排成排；司机喊乘客上车——嗡！出发！

### 3 · Muddy tractors 拖拉机

Down by the station,  
Early in the morning,  
See the **muddy tractors**,  
All in a row.  
See the **tractor driver**  
Loading up the trailer;  
**CHUG! CHUG! CHUG!**  
And off we go! — 沾泥的拖拉机；司机往拖车上装货——恰咯！出发！

### 4 · Shiny taxi cabs 出租车

Down by the station,  
Early in the morning,  
See the **shiny taxi cabs**,  
All in a row.  
See the **taxi driver**  
Polishing the windows;  
**BEEP! BEEP! BEEP!**  
And off we go! — 锃亮出租车；司机擦车窗——嘀！出发！

### 5 · Great big trucks 大货车

Down by the station,  
Early in the morning,  
See the **great big trucks**,  
All in a row.  
See the **truck driver**  
Loading up the parcels;  
**HONK! HONK! HONK!**  
And off we go! — 大卡车；司机装包裹——叭！出发！

### 6 · Fire engines 消防车

Down by the station,  
Early in the morning,  
See the **fire engines**,  
All in a row.  
See the **fire fighter**  
Climbing up the ladder;  
**NEE! NOR! NEE! NOR!**  
And off we go! — 消防车；消防员爬梯子——呜啦！出发！

## 跟唱提示 · Sing-along tips

| 节 | 动作 / 拟声 | 简中 |
| --- | --- | --- |
| Down by the station | 手指向「车站」方向 | 车站边 |
| Early in the morning | 揉眼睛、打哈欠 | 大清早 |
| All in a row | 手臂一排比划 | 排成排 |
| Pull the handle | 握拳往下拉 | 拉把手 |
| CHUFF! | 短促喷气声 + 握拳前推 | 火车喷气 |
| Calling to passengers | 手拢嘴边喊 | 喊乘客 |
| BRRM! | 双手握方向盘转 | 公交发动 |
| Loading trailer / parcels | 弯腰做搬箱动作 | 装货 |
| CHUG! / HONK! | 慢转 / 按喇叭手势 | 拖拉机 / 卡车 |
| Polishing windows | 转圈擦玻璃 | 擦窗 |
| BEEP! | 食指按两下 | 出租车嘀 |
| Climbing ladder | 手脚交替往上爬 | 爬梯子 |
| NEE! NOR! | 双手挥、做警笛声 | 消防车呜啦 |
| And off we go! | 双臂向前「开走」 | 出发啦！ |

## 时态说明 · Tense in the lyrics

像在描述**每天早上车站边正在发生**的一幕，动词以**一般现在时**为主（与 [[learning-notes/english-song/Celine/ClassicBooksWithHoles/TheWheelsOnTheBus|The Wheels on the Bus]] 同类）。

### 1 · 时间标志：Early in the morning

**Early in the morning** — 大清早、每天早上。不是 *yesterday* 讲故事，而是**习惯性场景**：*Every morning we **see** the trains…*

### 2 · 现在时动词一览

| 动词 | 形式 | 简中 | 歌词句 |
| --- | --- | --- | --- |
| **see** | 原形 | 瞧见 | **See** the little puffer trains |
| **pull** | 原形 | 拉 | **Pull** the little handle |
| **call** | **-ing** | 正在喊 | **Calling** to the passengers |
| **load** | **-ing** | 正在装 | **Loading** up the trailer / parcels |
| **polish** | **-ing** | 正在擦 | **Polishing** the windows |
| **climb** | **-ing** | 正在爬 | **Climbing** up the ladder |
| **go** | 原形 | 走；出发 | And off we **go**! |

**See / Pull** 用原形：儿歌里常把动作当成「口令」，像在指挥现场。

**Calling / Loading / Polishing / Climbing** 用 **-ing**：动作**正在进行**。

### 3 · And off we go!

**Off we go!** = **We go off!**（我们出发啦！）— 口语里把 **off** 提前，更有劲。整首歌每节重复，适合跟 Celine 边做开车手势边喊。

### 4 · 和《Five Little Men》对比

| | 本歌 *Down by the Station* | [[learning-notes/english-song/Celine/ClassicBooksWithHoles/FiveLittleMen|Five Little Men]] |
| --- | --- | --- |
| 时态 | **现在时** see, pull, calling, off we go | **过去时** flew, looked, came back |
| 感觉 | 清晨车站**正在热闹** | *One day* **已经发生过**的事 |
| 例句 | **See** the busy buses. | They **looked** left and right. |

## 车辆认读小练习 · Vehicle drill

唱完一节，问 Celine：

| 问 | 答 |
| --- | --- |
| Where are we? | **Down by the station.** |
| When? | **Early in the morning.** |
| How are the trains? | **All in a row.** |
| What sound for the train? | **CHUFF! CHUFF! CHUFF!** |
| What does the bus driver do? | **Calling** to the passengers. |
| How do we end every verse? | **And off we go!** |

**进阶：** 按顺序说六种车 — *trains → buses → tractors → taxis → trucks → fire engines*.
