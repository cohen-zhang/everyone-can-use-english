# 小区生活场景 · Community Life & Outdoor（深圳商品房）

## 本页在做什么

面向**深圳典型商品房小区**的**户外生活场景**：按 **下楼出门 → 大堂 Lobby → 小区内游乐场 → 与小伙伴游戏 → 游泳池 → 取快递 → 丢垃圾 → 小区外河边散步／跑步** 顺序列常用英文词，配 **IPA（英 / 美）** 与场景对话。便于带娃（**不多 / Celine**）日常户外活动、与邻居／物业／快递沟通。不含具体小区名、门牌号等隐私。

---

## 阅读顺序（建议出门动线）

典型路线：**换鞋出门 → 等电梯下楼 → 经过大堂 → 走向游乐场／泳池 → 取快递 → 丢垃圾 → 小区外河边活动 → 回家进大堂 → 等电梯上楼**。

| 顺序 | 分区 | 典型场景 |
|:---:|---|---|
| ① | **出门准备** | 换鞋、带水壶、拿门禁卡 |
| ② | **电梯厅** | 等电梯、按键、出电梯 |
| ③ | **大堂 Lobby** | 经过前台、问候保安、休息区等候 |
| ④ | **小区花园** | 漫步道、绿化区、认植物 |
| ⑤ | **游乐场** | 滑梯、秋千、沙坑、与小伙伴玩 |
| ⑥ | **游泳池** | 更衣、下水、游泳、休息 |
| ⑦ | **快递点** | 丰巢柜、驿站、扫码取件 |
| ⑧ | **垃圾站** | 分类投放、厨余／可回收／其他 |
| ⑨ | **河边户外** | 散步、跑步、看风景、放风筝 |
