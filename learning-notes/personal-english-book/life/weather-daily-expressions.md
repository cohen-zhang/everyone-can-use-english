# Weather — 天气

**索引：** [[learning-notes/personal-english-book/README|个人英文材料书索引]]

日常聊天气、看 **Weather**（天气）应用、带娃出门前的几句英文，都在这里对照练习。

---

## 1. iPhone 上的 **Weather** 应用 — 界面与操作

| English | 简中 |
|--------|------|
| Open the **Weather** app. | 打开「天气」应用。 |
| **Current conditions** | 当前天气状况 |
| **Hourly forecast** | 逐小时预报 |
| **10-day forecast** / **daily forecast** | 十天预报 / 每日预报 |
| **Feels like** … | 体感温度…… |
| **High** / **Low** (temperature) | 最高温 / 最低温 |
| **Precipitation** chance | 降水概率 |
| **Humidity** | 湿度 |
| **UV index** | 紫外线指数 |
| **Wind speed** / **wind gusts** | 风速 / 阵风 |
| **Air quality** (AQI) | 空气质量指数 |
| **Sunrise** / **sunset** | 日出 / 日落 |
| **Severe weather alert** | 恶劣天气预警 |
| **Radar** map | 雷达图（降水云图） |
| **Location** / **Add Location** | 位置 / 添加城市 |
| **Search** for a city | 搜索城市 |
| **Widget** on the Home Screen | 主屏幕小组件 |

**泽哥**可以这样说（读英文即可，括号内是意思）：

- **It says it’ll rain this afternoon.** — 上面写下午会下雨。
- **The high today is 28°C.** — 今天最高 28 度。
- **There’s a 60% chance of rain.** — 有六成概率下雨。
- **The air quality looks good.** — 空气质量看起来不错。

## 2. 常见天气 — 词与短句

| Weather | 简中 | 一句可用 |
|--------|------|----------|
| **Sunny** / **clear** | 晴天 / 晴朗 | It’s sunny today. |
| **Partly cloudy** | 多云间晴 | It’s partly cloudy. |
| **Cloudy** / **overcast** | 阴 / 阴天 | It’s cloudy; the sky is gray. |
| **Foggy** / **misty** | 有雾 / 薄雾 | It’s foggy this morning. |
| **Rainy** / **drizzle** | 下雨 / 毛毛雨 | Light drizzle; take an umbrella. |
| **Showers** | 阵雨 | Scattered showers this afternoon. |
| **Thunderstorm** | 雷雨 | A thunderstorm is coming. |
| **Windy** / **breezy** | 大风 / 微风 | It’s windy; hold your hat. |
| **Snow** / **snowy** | 雪 / 下雪天 | It might snow tonight. |
| **Hail** | 冰雹 | Hail can damage cars. |
| **Hot** / **humid** / **muggy** | 热 / 潮湿 / 闷热 | It’s humid; I’m sweating. |
| **Cold** / **freezing** | 冷 / 冻 | It’s freezing outside. |
| **Heat wave** | 热浪 | We’re in a heat wave. |

**地区提示**：英式常说 **brilliant sunshine**（大晴天）；美式日常里 **It’s nice out** 很常见，意思是「外面天气挺好」。

## 3. 出门前后 — 亲子对话（**不多** & **Celine**）

### 晴天 / 暖和

- **Dad:** It’s sunny and warm. Do you want to wear a T-shirt? — 又晴又暖，要穿 T 恤吗？
- **Celine:** Yes! Can we go to the park? — 要！能去公园吗？
- **Dad:** Sure. Don’t forget your water bottle. — 行。别忘了水壶。

### 多云 / 可能要下雨

- **Dad:** It’s cloudy. The Weather app says rain later. — 阴天，天气里说等会儿要下雨。
- **Celine:** Do I need my rain boots? — 要穿雨靴吗？
- **Dad:** Good idea. Let’s take an umbrella, too. — 好主意，咱们再带把伞。

### 正在下雨

- **Dad:** It’s raining. Put on your raincoat. — 在下雨，穿上雨衣。
- **Celine:** I hear thunder! — 我听到打雷了！
- **Dad:** Let’s stay inside until the storm passes. — 咱们先待在屋里，等暴雨过去。

### 刮风

- **Dad:** It’s really windy. Hold my hand. — 风很大，牵好我的手。
- **Celine:** My hat almost flew away! — 我的帽子差点飞了！

### 冷 / 冬天

- **Dad:** It’s cold today. Wear your jacket and scarf. — 今天冷，穿上外套和围巾。
- **Celine:** Can I wear gloves? — 能戴手套吗？
- **Dad:** Yes, and a hat. We don’t want frostbite. — 可以，还有帽子。咱们可别冻伤。

### 热 / 夏天

- **Dad:** It’s scorching hot. Let’s drink water first. — 太热了，先喝点水。
- **Celine:** Can we go swimming? — 能去游泳吗？
- **Dad:** Maybe later, when it’s not so hot at noon. — 也许晚点，中午别顶着大太阳去。

### 看 **Weather** 决定行程

- **Dad:** Let me check the Weather app… No rain until evening. We can bike after lunch. — 我看下天气……傍晚前没雨，午饭后可以骑车。
- **Celine:** Yay! — 好耶！

## 4. 幼儿园 / 学校场景 — 短句

- **How’s the weather today?** — 今天天气怎么样？
- **What’s the weather like?** — 天气如何？（和上一句常可互换）
- **We can’t have PE outside; it’s raining.** — 外面下雨，体育课不能去室外。
- **Recess is indoors because of the storm.** — 因为暴风雨，课间休息在室内。

## 5. 阿泽自练 — 替换词造句

用同一骨架换天气词，多读几遍就顺口：

1. **It looks like** **[sunny / rainy / windy]** **weather tomorrow.** — 明天看起来是……天。
2. **According to the Weather app,** **we should** **[stay home / bring jackets / leave early].** — 据天气应用，我们应该……
