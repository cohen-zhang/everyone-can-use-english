## 三、学习方法总结 Learning Methodology

### 核心原则 Core Principles

| 原则 Principle | 说明 Explanation |
|---------------|------------------|
| 句子是最小单元 Sentence is the minimum unit | 学习英语的时候，一定要学习一个完整的句子，不要只记单词。在学英语句子的时候，要把句子的语法、语调和发音腔调完整学起来。—— 林语堂 When learning English, always learn complete sentences, not just words. Learn grammar, intonation, and pronunciation together. |
| 用起来！Use it! | 句子才是最小单元，用起来！用起来！用起来！ Sentences are the minimum unit - use it, use it, use it! |
| 读音优先 Pronunciation first | 把"认识单词"的标准定高点，不仅仅是在句子中认识，还要会拼写和读音；读音会影响听力 Raise the standard for "knowing a word" - not just recognizing it in sentences, but also spelling and pronunciation |
| 词典英英释义 English-English dictionary | 词典优先英-英释义 Prioritize English-English dictionary definitions |
| 输入→理解→输出→复习 Input→Understand→Output→Review | 只是"听"，但没有形成输入→理解→输出→复习的闭环 Just "listening" without forming the Input→Understand→Output→Review loop |

**Q: 什么是 IoC？**
**A**: In software engineering, inversion of control (IoC) is a programming principle. IoC inverts the flow of control as compared to traditional control flow. In IoC, custom-written portions of a computer program receive the flow of control from a generic framework. A software architecture with this design inverts control as compared to traditional procedural programming: in traditional programming, the custom code that expresses the purpose of the program calls into reusable libraries to take care of generic tasks, but with inversion of control, it is the framework that calls into the custom, or task-specific, code.

在软件工程中，控制反转(IoC)是一种编程原则。IoC反转了与传统控制流相比的控制流程。在IoC中，计算机程序中自定义编写的部分从通用框架接收控制流。采用这种设计的软件架构与传统过程式编程相比反转了控制：在传统编程中，表达程序目的的自定义代码调用可重用库来处理通用任务，但在控制反转中，是框架调用自定义的或特定任务的代码。
