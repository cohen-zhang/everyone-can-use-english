## 中文（说明向）

**苹果 MacBook Pro（14 英寸，Apple M4 芯片，24 GB 统一内存）** 是我每天写 Java、跑 IDE、开终端、看日志、跑 JUnit 的那台机器。它不是摆设，而是跟需求会、UML、SQL、service 层、集成测试、staging、偶尔 prod 救火一起过日子的搭档：屏幕够大、机身够轻，带出门开会或在家加班都顺手；24 GB 对多开 IDE、本地 Docker、浏览器一堆 tab 和测试进程来说，属于能扛住日常 backend 节奏的配置。M4 的续航和安静风扇，也让「改代码 → 跑测试 → 再看一眼日志」这种循环不那么折磨人。简单说：**它是把脑子里的 Java 和图纸上的框线，变成可运行、可上线、可回滚的那层硬件底座。**

## English — diary / script style

> **Tone:** One dev talking to the camera — same vibe as the work diary. Pauses: `/`

**My daily driver is a 14‑inch MacBook Pro with Apple’s M4 chip and 24 GB of unified memory.** / On paper it’s “just a laptop,” but in practice it’s the workstation where my **Java** backend work actually happens: **IDE**, **Git commits**, **JUnit** runs, **integration tests** against **APIs**, **SQL** and migrations, **logs** when something looks wrong in **staging** — and, on a spicy day, the same machine that helps me trace a bad **join** and ship a **hotfix** without losing my mind. / The M4 keeps the machine responsive and quiet through long compile/test loops, and **24 GB** is the difference between “I can keep Docker + browser + tests alive” and “everything starts swapping and my focus dies.” / If my job is **talk → draw → migrate → commit → test → deploy**, this MacBook Pro is the **hardware partner** that sits through every beat of that rhythm with me.
