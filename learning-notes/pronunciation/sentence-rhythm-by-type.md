## 2. 节奏五要素

摘自 [英文语音简明教程](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/new-edition-drafts/%E8%8B%B1%E6%96%87%E8%AF%AD%E9%9F%B3%E7%AE%80%E6%98%8E%E6%95%99%E7%A8%8B.md)「高低起伏轻重缓急」与 [1000h · 4.5.6](https://1000h.org/sounds-of-american-english/4.5-sentences.html)：

| 要素 | 英文 | 要点 | 延伸阅读 |
|------|------|------|----------|
| **停** | pause | 意群之间较长空隙，可换气；断句影响意义 | [4.3.2 停](https://1000h.org/sounds-of-american-english/4.3-grouping.html#432-停暂停-pause) |
| **顿** | stop | 音节 / 词内极短空隙；失爆、连读前常见 | [4.3.3 顿](https://1000h.org/sounds-of-american-english/4.3-grouping.html#433-顿停顿-stop) |
| **轻重** | accent / weak | 内容词强读，功能词弱读 → schwa | [[learning-notes/pronunciation/syllable-division-ipa-based#65-句内强读与弱读|§6.5]] |
| **起伏** | intonation | 重音音节上的平 / 升 / 降调 | [ch.3 §19](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/book/chapter3.md#19-技巧加重点声调) |
| **缓急** | tempo | 强调词放慢，弱读词压缩 | [4.5.6 语速](https://1000h.org/sounds-of-american-english/4.5-sentences.html) |

**Step-up-and-step-down（[ch.3 §23](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/book/chapter3.md#23-音调pitch)）：** 每个意群里，**第一个被强读的词**的重音音节 pitch 抬高，随后音节逐步降低——不必等整句开头。

**标记符号（跟读用）：**

| 符号 | 含义 |
|------|------|
| **加粗** | 强读词 |
| `\|` | 意群边界（停） |
| `△` | 该词重音音节 pitch 抬高 |
| `1` `2` `4` `0` | 中文声调类比：平 / 升 / 降 / 轻声（见 [[learning-notes/pronunciation/english-phonetics-textbook#part-vii--音高节奏与声调|完整教程 · Part VII]]） |

## 3. 按句型的节奏规律

语法四类 + 疑问句子类，与 [[learning-notes/grammar-lab/english-language-taxonomy#31-按语气--功能四类|grammar-lab · §3.1]] 对齐。

> **说明：** 下表「倾向」非硬规则；**对比重音**、**情绪**、**是否列举**都会改变哪几个词被强读。以真人音频为准。

### 3.1 陈述句 · declarative

| | |
|---|---|
| **节奏要点** | 功能词（*the, a, of, to, is*…）多弱读；内容词强读；意群末多**降调**收束 |
| **国人易错** | 每个字等长、功能词读太重、整句一条调平推过去 |

**例句（加粗 = 强读）：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | **Community** **service** is an **important** **component** of **education** **here** at our **university**. | 经典跟读段；第二处 *community* 弱读 → [ch.3 §12](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/book/chapter3.md#12-自然语流中的强读与弱读现象) |
| 职场 | The **deploy** failed at **midnight**. | *The* /ðə/ · *at* /ət/；**deploy**、**midnight** 拉长 |
| 亲子 | The **ceramic** bowl is **hot**. | **ceramic** /sə-ˈræm-ɪk/ 词重音在第二音节；**hot** 句末降调 |

**意群切分示例：**

> The **ceramic** bowl \| is **hot**.

---

### 3.2 一般疑问句 · yes-no question

| | |
|---|---|
| **节奏要点** | 助动词 / **be** / 句末核心词常获重读；整句或末音节常**升调**（寻求 yes/no） |
| **国人易错** | 升调加在错误音节；每个词都读满、没有弱读 |

**例句：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | **Are** you **awake**? | **Are** 强读 + 末词 **awake** 升调 |
| 职场 | **Can** we **roll back** the **release**? | **Can** /kən/ 可弱可强（强调「能不能」时强读）· **roll back** 两拍清楚 |
| 亲子 | **Is** the **soup** **ready**? | *Is* /ɪz/ 或 /z/ 弱读 · **ready** 升调收句 |

---

### 3.3 特殊疑问句 · wh- question

| | |
|---|---|
| **节奏要点** | **Wh- 词** + **内容词**强读；信息焦点清楚；多数情况整句**降调**收束（不像 yes-no 那样句末大升） |
| **国人易错** | wh- 词读太轻；句末误用升调（像 yes-no） |

**例句：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | **Where** is my **cup**? | **Where** /wer/ 降调 · *is* /ɪz/ 弱 · **cup** 降调 |
| 职场 | **Why** did the **build** **fail**? | **Why**、**build**、**fail** 三拍；*did* /dɪd/ 弱 |
| 亲子 | **What** **shape** is this? | **What** **shape** 连读前要有气口；**this** 降调 |

---

### 3.4 反义疑问句 · tag question

| | |
|---|---|
| **节奏要点** | 主句多**降调**陈述；**tag** 部分（*aren't you?*, *isn't it?*）常**升调**（真问）或**降调**（求认同） |
| **国人易错** | tag 读成和主句一样平；*aren't* 每个音都读满 |

**例句：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | You're **coming**, **aren't** you? | 主句降 · **aren't you** 升（等你确认） |
| 职场 | The **fix** is **done**, **isn't** it? | 求认同时 tag 也可降调 |
| 亲子 | **Celine**, you're **ready**, **aren't** you? | 呼名 **Celine** 独立意群，pitch 抬高 |

---

### 3.5 祈使句 · imperative

| | |
|---|---|
| **节奏要点** | 省略 **you**；**动词原形**（及宾语核心词）重读；句子短、意群少；节拍要**清楚**（指令 / 安全） |
| **国人易错** | 动词读太轻；多个词糊成一拍 |

**例句：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | **Sit** **down**. | 两拍，均重读；句末降 |
| 职场 | **Roll** **back** to the **last** **tag**. | **Roll back** 两动词拍 · *to the* 弱读 |
| 亲子 | **Put** on your **shoes**, **Celine**. | **Put**、**shoes** 重 · *on your* 弱 · 呼名降调 |

---

### 3.6 感叹句 · exclamatory

| | |
|---|---|
| **节奏要点** | 情绪词 / **What·How + 名词/形容词** 拉长、音高幅度大；常含 **Wow** 等感叹词独立意群 |
| **国人易错** | 音高起伏不够；关键词读太短 |

**例句：**

| 场景 | 句子 | 节奏提示 |
|------|------|----------|
| 通用 | **Wow**, a **rainbow**! | **Wow** 高 pitch · **rainbow** 拉长降调 |
| 职场 | **What** a **mess**! | **What** / **mess** 两拍都重 · 降调 |
| 亲子 | **How** **fast** you **run**! | **How** **fast** 拉长 · **run** 降调收句 |

## 4. 对比重音 · 同一句话，强调不同词

摘自 [1000h · 4.5.2](https://1000h.org/sounds-of-american-english/4.5-sentences.html#452-强读词汇)：陈述句节奏不只由「句型」决定，还由**信息焦点**决定。

**Marianna made the marmalade.** —— 四个版本，强读位置不同，含义不同：

| 版本 | 强读 | 暗示 |
|------|------|------|
| 1 | **Marianna** made the marmalade. | 是她做的，不是别人 |
| 2 | Marianna **made** the marmalade. | 是她「做」的，不是买/偷的 |
| 3 | Marianna made the **marmalade**. | 做的是 marmalade，不是别的 |
| 4 | Marianna made the marmalade**?** | 升调 → 疑问 / 确认 |

**Will you drive to the office tomorrow?** —— 强读词随焦点移动：

- **Will YOU drive…**（不是别人）
- Will you **DRIVE**…（不是坐别的交通工具）
- Will you drive **TO** the office…（不是从 office 出发）
- Will you drive to the **OFFICE**…（不是别的地方）
- Will you drive to the office **TOMORROW**?（不是别的一天）

## 5. 标记与跟读工作流

压缩自 [ch.3 §26](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/book/chapter3.md#26-跟读训练具体步骤)：

```text
1. 精读：查生词 IPA + 词重音
2. 标强读：圈出内容词 / 焦点词
3. 切意群：| 之间可换气
4. 标 pitch：△ 放在意群首 nuclear accent 上
5. 标声调：重音音节旁写 1 / 2 / 4 / 0（可选，见 Part VII）
6. 慢跟读 → 正常语速 → 录音 → 隔一周再听对比
```

**改写练节奏（语法 + 语音）：**

1. 陈述 → 一般疑问：*The deploy failed.* → *Did the deploy fail?*
2. 陈述 → 祈使：*You should roll back.* → *Roll back.*
3. 陈述 → 感叹：*It is a mess.* → *What a mess!*

同一组词，**强读位置与句末调型**都会变——先改语法，再标新节奏。

## 7. 阿泽速查清单

- 先弱读功能词，再强读内容词；不要词典式朗读。
- 陈述句：意群末降；yes-no 问句：末词常升。
- wh- 问句：wh- 词不能读成轻声；整体多降调收束。
- 祈使句：动词拍要清楚（亲子 / 安全指令尤甚）。
- 同一陈述句，换强调词 = 换节奏（§4）。
- 节奏优先于「每个音素完美」—— [ch.3 §12](https://github.com/ZuodaoTech/everyone-can-use-english/blob/master/book/chapter3.md#12-自然语流中的强读与弱读现象)。
