# 看电影学英语 · 方法摘要

**出处：** [[book/chapter8|《人人都能用英语》ch.8 §6]]  
**索引：** [[learning-notes/tv-series/README|tv-series 索引]] · [[learning-notes/personal-english-book/README|个人英文材料书索引]]

> 不是捷径；兴趣也没那么重要。真牛的是：**尽管没兴趣，但只要该学就能学会。**  
> 怕麻烦的人啥都做不好——但三五部之后，多数片子能听懂八九成。

---

## 1. 核心流程（按顺序做）

```text
选片下载 → 搜英文字幕 (srt) → 精读字幕查词 → 自制词表
    → 先无字幕试看 → 吃力再开英文字幕（绝不看中字）
    → 复习词表 2–3 遍 → 再看一遍电影
```

| 步骤 | 做法 | 注意 |
| --- | --- | --- |
| **1. 找字幕** | Google：`电影名 发行年份 English subtitle` | 例：`12 Angry Men 1957 English subtitle`；本库例：`Spider-Man Into the Spider-Verse 2018 English subtitle` |
| **2. 只要 srt** | 纯文本，记事本 / VS Code 可直接打开 | 勿优先 ASS/SUP 等二进制字幕 |
| **3. 精读字幕** | 全选拷贝 → 文档里精读 | 查生词；**识别词组**，不只查单词 |
| **4. 自制词表** | 只收你当时不稳的词 / 搭配 | 参考「把 Word 打造成学习利器」；本库用 Markdown 表即可 |
| **5. 再看电影** | 先无字幕；吃力再开**英文**字幕 | **绝对不要看中文字幕**；不懂查词典 |
| **6. 复习 + 二刷** | 词表复习两三遍，再看一遍 | 不必一辈子这么啰嗦——熟练后会快很多 |

---

## 2. 预期与边界（诚实版）

- **靠看电影提高英语，程度相当有限。** 片子靠画面讲故事，动作往往多于对话。
- 动作片常见片语：*Drop it!* · *Go! Go! Go!* ——有用但不够撑起词汇量。
- 文艺片词藻也往往**窄**；**海量阅读**通常更直接、更有效。
- 剧集差异很大：有的 ~2000 词够用；历史剧略难；医学剧（如 *House*）术语其实就一百来个；俚语剧对初学者用处不大；台词精致的剧（如 *The West Wing*）难且少人真练。

**结论：** 电影/剧集是**精读 + 听力**的练习场，不是「看热闹就会英语」的捷径。想学，就按上面流程做完词表再开片。

## 4. 一分钟自检

1. 字幕是不是 **英文 srt**？  
2. 开片前有没有**自己的词表**（不是「边看边猜」）？  
3. 看片时有没有开中文字幕？（有 → 重来）  
4. 看完有没有**复习词表 + 二刷**？
