# 《摩登家庭》S01 — 学习材料索引

本目录收录 **第一季（S01）** 与《摩登家庭》相关的英文学习笔记，字幕源文件在仓库的 `美剧/摩登家庭 S01/`。

## 文件类型


| 类型                                                | 说明                                                              |
| ------------------------------------------------- | --------------------------------------------------------------- |
| **S01EXX-生活实用英文句.md**                             | 从对应 `摩登家庭 S01-XX.txt` **自动抽取**英中句对，按粗分类（出行、居家、亲子等）分组；适合快速刷句、跟读。 |
| **S01E02-What's the key to being a great dad.md** | **手工编排**的亲子对话体练习（张泽 / Celine 设定），与自动抽取版互补。                      |
| **scripts/build_modern_family_s01_md.py**         | 生成「生活实用英文句」的脚本；字幕更新后可重新运行。                                      |


## 剧集列表


| 集数      | 生活实用句（book）                                                                                                    | 字幕（txt）                          |
| ------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| E01     | [S01E01-生活实用英文句.md](S01E01-生活实用英文句.md)                                                                         | `美剧/摩登家庭 S01/摩登家庭 S01-01.txt`    |
| E02     | [S01E02-生活实用英文句.md](S01E02-生活实用英文句.md) + [亲子主题对话](S01E02-What's%20the%20key%20to%20being%20a%20great%20dad.md) | `摩登家庭 S01-02.txt`                |
| E03–E24 | `S01E03` … `S01E24` 同命名规则                                                                                      | `摩登家庭 S01-03.txt` … `S01-24.txt` |


**说明：** E12 若字幕文件为空，对应 `S01E12-生活实用英文句.md` 内会有占位说明；补齐字幕后请重新运行脚本。

## 重新生成「生活实用英文句」

在仓库根目录执行：

```bash
python3 book/摩登家庭/scripts/build_modern_family_s01_md.py
```
