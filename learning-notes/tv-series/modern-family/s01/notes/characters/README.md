Adult-oriented character guides built from **show lines and phrases** in S01 transcripts and daily-lines notes.  
面向**成人**英文训练的人物导读：尽量用剧中原句与口头梗，配合跟读、复述和语域辨析。

---

## How to Use

1. Read the **Short Introduction（短文）** once for the character arc in plain English.  
   先读短文，建立人物整体印象。
2. Shadow-read **Signature Lines** aloud; note tone (joke, threat, warmth, sarcasm).  
   跟读「核心台词」，注意语气是玩笑、威胁、温情还是讽刺。
3. Open the linked **daily-lines** or **transcript** episode for full context.  
   需要语境时，点开对应集的 daily-lines 或字幕全文。
4. Use **Adult Practice** prompts for retelling—not parent-child role-play.  
   「成人练习」用于复述与改写，不是亲子扮演。
