# tv-series · 影视学英语索引

**方法：** [[learning-notes/tv-series/how-to-learn-english-from-movies|看电影学英语 · 方法摘要]]（[[book/chapter8|《人人都能用英语》ch.8 §6]]）

---

## 方法一览（原书要点）

1. 搜英文字幕：`电影名 年份 English subtitle` → 只要 **srt**  
2. **精读字幕** → 查词 / 词组 → **自制词表**  
3. 先无字幕试看；吃力再开**英文字幕**（**不开中字**）  
4. 复习词表 2–3 遍 → 再看一遍  

完整步骤与边界说明见方法页；**不是捷径**，海量阅读通常更有效。
