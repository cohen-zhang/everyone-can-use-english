*成人向精简：读者默认 **简中母语、成人**，目标含工作/日常口语。**「低频」**兼指「通用英语里仍少遇」或「对中国成人学习者仍值得本片收束」——不等于台词出现次数少。收录拼写/读音/搭配难点与片中高价值 chunk；剔除无教学价值的超高频碎片、纯拟声。*

**用法（对齐原书）：** 先精读本表 → 再无字幕试看 → 吃力开英文字幕 → 复习词表 2–3 遍 → 二刷。

## 3. 口语与语域（听写易漏）

| 字幕常见写法 | 展开 / 说明 | 简中 |
| --- | --- | --- |
| **gonna / gotta / wanna** | going to / got to / want to | 将要 / 得 / 想要 |
| **'cause** | because | 因为 |
| **dunnah / DNA** | 片中 Gideon 把 *DNA* 读错，Travis 纠正 | 听懂笑点即可 |
| **Wezzleton / Weaselton** | 角色名；Judy 读错被纠正 | 专名听写 |
| **sweetheart** | 亲爱的（可亲昵也可带嘲讽） | 宝贝儿 |

## 4. 精读自检（做完词表再开片）

1. 能脱稿说出 **Anyone can be anything.** 与 **Sly fox, dumb bunny.**  
2. 能解释 **Night Howlers** 的「狼 → 花」反转，以及 **Fear always works.**  
3. 听到 **meter maid / parking duty / hustle / going savage / serum** 知道大意  
4. **绝不**开中文字幕；不懂查词典或回看本表

## 朗读串联记忆 · Read-aloud chain

*约 1 分钟 · 先英后对照简中*

### A. 分句场景链

- **Anyone can be anything.** — 人人皆可成就任何事。
- **Sly fox, dumb bunny.** — 狡猾的狐狸，蠢兔子。
- **It's called a hustle, sweetheart.** — 这叫套路，亲爱的。
- **Night Howlers aren't wolves, they're flowers.** — 夜嚎者不是狼，是花。
- **Fear always works.** — 恐惧总是管用。
- **We cannot let fear divide us.** — 不能让恐惧分裂我们。

### B. 一段串联

**Anyone can be anything. Sly fox, dumb bunny. It's called a hustle, sweetheart. Night Howlers aren't wolves, they're flowers. Fear always works. We cannot let fear divide us.**

**简中：** 人人皆可成就任何事。狡猾的狐狸，蠢兔子。这叫套路，亲爱的。夜嚎者不是狼，是花。恐惧总是管用。不能让恐惧分裂我们。
